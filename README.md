# HealthPocket

Migration vers la version mobile Expo en cours.

Repository contenant:

- `mobile/`: application mobile React Native/Expo (nouveau socle).
- `web` (racine historique): ancien frontend React/Vite en cours de retrait.

## Commandes recommandees (depuis la racine)

```bash
npm run start
npm run android
npm run ios
npm run web
npm run typecheck
npm run build
```

Ces commandes deleguent vers `mobile/`.

## Lancer directement dans `mobile/`

```bash
cd mobile
npm install
npm run start
```

Documentation mobile detaillee: `mobile/README.md`.
